**First test build of the Glass Edition.** This build is for testing the new interface in the game.

### What's new
- Redesigned overlays in a minimal glass style: pet cards, the crystal wallet bar and the Cloud Merchant panel.
- New settings window with a live status card, switches and an opacity slider.
- New Npcap setup screen and a dark tray menu.

Tracking, capture and saving are unchanged from upstream release 1.0.2. See [what changed](https://github.com/TasosK7/Aion2PetTracker/blob/v1.1.0-glass.1/docs/FORK-NOTICE.md).

### Install
1. Download **Aion2-Pet-Tracker.zip** below and extract it.
2. Run **Aion2PetTracker.exe**. The EXE is not code-signed, so if SmartScreen warns you, choose **More info → Run anyway**.
3. Install [Npcap](https://npcap.com/#download) once if you are prompted.
4. **Start the tracker first, then AION 2.**

To keep your progress from another copy of the tracker, copy its **Daten** folder next to the new EXE.

### Please check
- How the overlays look in game, and whether they are readable over bright and dark scenes.
- Hover, clicking and keyboard use of the settings switches, slider and buttons.
- Dragging, locking and Alt-Tab behaviour of the overlays, and the Cloud Merchant panel at the shop.
- Behaviour on high-DPI or multi-monitor setups.
